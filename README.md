# Gamepad Support Mod

Adds native gamepad / controller support to the game.

How to Install

1. Download the latest `.dll` file from the https://github.com/Huuluan123/TheChariotGamepadMod/releases/tag/release* page.
2. Drop the downloaded `.dll` directly into the game's root folder (the folder containing the game's `.exe`).
3. Connect your controller and launch the game!

---

*To uninstall: Simply delete the `.dll` file from the folder.*
